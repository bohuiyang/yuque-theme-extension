Knowledge Base Migration Review

This fixture simulates a Yuque reading page and verifies theme coverage for headings, body text, Yuque links, quotes, code, tables, dividers, media, and outline content.

Migration Goals

  • Keep the original Yuque reading structure intact.
  • Make long-form reading feel closer to Obsidian Blue Topaz.
  • Ensure code blocks and tables remain readable in light and dark themes.
New Yuque Renderer Elements This fixture also includes current Yuque custom elements such as ne-p, ne-h2, and ne-quote. These custom elements should be detected as document content and receive the active reading theme.
Important conclusions should stand out from body text without breaking the page layout or document controls.

Inline code example: data-yuque-theme="blue-topaz-light".

const settings = {
  enabled: true,
  theme: "blue-topaz-light"
};
